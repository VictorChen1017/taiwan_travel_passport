# 開發日誌 2026-11-21 第 4 份

期間：第 3 份之後 ～ 2026-11-21 晚｜commit：`26b4269`～本份日誌（最後一個 commit 未 push）

## 完成的功能

- 手機照片實機測試頁 `dev/phone-gps.html`：比較各種選取方式能不能讀到 GPS，可複製不含座標的摘要
- 「📱 手機照片（補點）」卡片：只在手機、平板出現，可從相簿選或從檔案選；每次選的照片追加進同一份「手機照片」，重複的不再加入，照片模式與制霸五色都能用
- 匯入結果彈窗：補點後跳到成就頁，再顯示新增幾筆、略過原因與目前總數
- 說明頁：新增手機照片小節、兩條已知限制（手機不能讀資料夾與 iOS 轉檔、Mac 照片 App 未實測）、常見問題「手機可以匯入整個相簿嗎？」

## 克服的難題

- 手機選照片會卡住 → 實測確認是 iOS 從照片圖庫選取時把 HEIC 轉成 JPEG（試了四種 accept 寫法都避不開），位置不會被剝除；改從「檔案」App 選可拿到原檔、不用轉檔，寫進說明當大量匯入的替代做法
- 補點不能蓋掉舊資料 → 手機照片固定成一份來源，新選的逐筆合併、座標與時間相同的視為同一張

## 對話檢討

- 做得好的：先做只讀 GPS 的測試頁，用實機數據（123 張、四種寫法）決定功能定位，沒有直接在正式頁面嘗試
- 要改進的：一開始沒查證就推測「accept 列出 HEIC 可能避免轉檔」，多了一輪 push 與實測；自動改檔腳本在 Windows 遇到中文編碼失敗，改回逐段編輯
- 下次的做法：能在電腦（模擬手機）驗證的改動只 commit、建議維護者先不 push；只有必須實機測試時才 push
