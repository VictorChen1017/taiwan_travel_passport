## 完成的功能

- 資料備份與轉移：匯出／匯入 JSON 備份，換電腦或手機接著用；較新的版本才詢問取代
- 手動紀錄：沒照片也能把去過的地點、山、車站加進來，日期可不填，可在明細裡刪除
- 成就報表：把成就做成寬 1080 的 PNG 長圖分享，六種預設組合、可填暱稱、隱藏日期
- 使用說明頁：匯入步驟、計算規則、隱私與對外連線清單、授權、常見問題

## 克服的難題

- 國家公園等「範圍」沒有座標可手動加入 → 匯出圖資時產生代表點，且只解鎖該成就、不誤解鎖村里
- 兩台裝置各自加手動紀錄 → 每筆獨立編號，匯入備份時逐筆合併
- 報表要在各瀏覽器一致、能輸出圖片 → 直接用 Canvas 畫，不靠截圖套件；徽章圖形與成就頁共用
- 淺色路線（黃、淺綠）上的白字看不清 → 依底色亮度自動換深色字
- 地圖圖磚的使用政策 → 查證各家條款後先用 OSM，設定集中一處，量大再換
- Apache 沒開、又要確認不依賴後端 → 用 Python 純靜態伺服器模擬 GitHub Pages 測試
