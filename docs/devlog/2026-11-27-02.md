# 開發日誌 2026-11-27 第 2 份

期間：第 2026-11-27-01 份之後 ～ 2026-11-27｜commit：本份日誌與功能一起 commit、push

## 完成的功能

- 播放動畫的手機回饋（第一份的實機測試結果）
  - 上方提示精簡成「可縮放平移・點區域可補點」，播放中只留「可縮放平移」
  - 左上角年月浮標拿掉白底框、字縮小（手機再小一點）；＋、－、💧、全圖移到左下角並縮小，播放動畫按鈕維持原大小
  - 播放中隱藏本島／金門／馬祖／全部切換、不能補點，點區域只顯示名稱
  - 頁面選「面積」時浮標改成「累積 X% 面積」
  - 預設起點：新解鎖最多的那一年（每月：那個月）往前一年開始播；播完再按 ▶ 也從這裡重播
- 匯出影片（播放中右下角「🎬 匯出影片」）：MP4（不支援時 WebM），直式 9:16 或方形 1:1
  - 標題沿用成就卡片的暱稱（兩邊共用）；比例記在這台
  - 影片只有標題、年月、「範圍・＋N 個・累積…」與地圖，按鈕不會錄進去；地圖範圍＝目前畫面看得到的地方
- 解鎖順序列表：日期不再折成兩行，名稱置中（縣市、鄉鎮、村里都是）
- 小修：快速連按兩次播放動畫時，地圖可能被蓋回一般上色

## 克服的難題

- 影片不用外部套件 → 瀏覽器內建 MediaRecorder 錄一張不在畫面上的 canvas，每格只畫一次、每 1/30 秒重貼，村里地圖也不卡
- 手機分享選單要「剛點過按鈕」才能開，錄完已經過很久 → 錄完再顯示「分享／儲存」讓使用者按
- 地圖繪製改成可以畫到任意 canvas（螢幕和影片共用一套），第一次命名和既有函式撞名，測試時發現後改名
- 測試瀏覽器擋 blob 影片播放，看不到成品 → 錄影途中直接擷取錄製用的 canvas 檢查畫面（電腦錄出的檔案確認是有效 MP4）

## 對話檢討

- 做得好的：開工前一次問完四個決定（每月起點、影片比例、暱稱來源、提示文字），其餘照回饋直接做
- 要改進的：撞名的錯誤讓第一次載入測試資料就壞掉，多花幾輪清資料重測；改大檔前應先搜尋同名函式
- 下次的做法：新增函式前先 grep 名稱；測試資料壞掉時先清 IndexedDB 再重載，不要在壞資料上除錯
