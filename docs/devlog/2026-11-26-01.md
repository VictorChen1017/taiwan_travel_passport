  - 場景與戳章文字由設定檔決定，之後新增節慶只要加設定與畫一張場景

## 克服的難題

- 歷年開閉城日期查不齊（維基百科只有演唱會日期）→ 逐年查新聞稿與媒體報導，查不到的年份用預設值並在設定檔註明
- 手動紀錄只有日期（中午 12:00），會被 18–22 點的時段擋掉 → 手動加入改成選年份、只看日期；其他地點的手動紀錄（例如板橋站）不會誤算進來
- 夜景在寬螢幕被上下裁掉、樹頂星星不見 → 夜景加寬到 200 格，右下對齊，窄螢幕從左邊裁
- 動圖格式：GIF 到處都會動但只有 256 色 → 自寫 GIF 編碼器（中位數切割調色盤、LZW、第二格起只存變動範圍），8 格約 99 KB、0.2 秒產生；自動檢查用瀏覽器解碼回來逐格比對

## 對話檢討

- 做得好的：開工前把要決定的事一次問完（期間判定、隱藏方式、格子、手動與分享），動圖前也先問格式與範圍；每次改完都跑自動檢查
- 要改進的：第一版漏了明細地圖的藍點、月亮擋到標題、分享圖片的版面沒有跟成就頁一起改，都是維護者看了才發現；驗證時用 import 重複載入 app.js 造成兩個彈窗，花了幾輪才找出是測試手法的問題
- 下次的做法：新類別上線前對照同類功能（地點類明細都有藍點）逐項比；成就頁與分享圖片的版面一起改；瀏覽器檢查不要用 import 載入有副作用的模組
