# 開發日誌 2026-11-26 第 3 份

期間：第 2026-11-26-02 份之後 ～ 2026-11-26｜commit：`a666b3d`（未 push；本份日誌另外 commit）

## 完成的功能

- 新手頁面導覽：畫面變暗、框出重點，加上說明泡泡，分兩段帶過「匯入資料 → 查看成就 → 匯出卡片」
  - 首頁那段：第一次打開、還沒有資料時自動開始（三步驟 → 資料來源）
  - 成就頁那段：匯入後第一次進成就頁時接著導（迷霧小地圖 → 探索率 → 成就徽章 → 分享成就）
  - 可以按「下一步」，也可以直接點框住的地方；點了照常執行（例：點小地圖會開放大地圖，關掉後導覽接下一步）
  - 首頁標語下、成就目錄都有「▶ 頁面導覽」可以重看；和時間軸圖文教學並存，不會疊在一起
- 導覽過場動畫：換步驟時框框滑過去、泡泡等捲動停了才淡入，開始與結束淡入淡出；系統開啟「減少動態效果」時不播

## 克服的難題

- 換步驟時卡頓 → 原本每次捲動都用程式重算遮罩、框框、泡泡的位置；改成整層跟著頁面原生捲動，捲動時不用重算，動畫只用不會重排版面的屬性
- 泡泡擺在捲動前的位置 → 平滑捲動有時晚一點才開始；改成確認已捲到目標位置才放泡泡（最多等 1.5 秒）
- 冒出橫向捲軸 → 導覽層寬度把捲軸寬度算進去了，改用不含捲軸的寬度
- 第一步的框框從左上角滑過來（維護者回報）→ 第一步與視窗縮放時直接到位，只有換步驟才補間
