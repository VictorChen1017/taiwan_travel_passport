# 第三版構想（2026-11-21 討論，尚未實作）

兩個題目都還沒動手，這份是現況分析、建議做法與待維護者決定的事。開新對話實作時先讀這份。

## 一、迷霧地圖界線有空隙、失真

### 原因

- `tools/export_static.php` 的 maps 段落對**每個鄉鎮（縣市、村里）各自**做 `ST_SimplifyPreserveTopology`
- 這個函式只保證「單一形狀自己不打結」，不管鄰居：兩個鄉鎮共用的那條界線被各簡化一次、留下的點不同，於是中間出現細縫或重疊
- 另外每個單位只留最大一塊，加上面積大於 2e-6 的小塊，所以很小的離島、沙洲會消失
- 判定用的 `villages.topo.json` 只量化、不簡化，**計算結果不受影響**，只影響畫面

### 建議做法：共用邊界只簡化一次（原理同 TopoJSON 的 simplify）

1. 原始界線先量化（同現在的 1e-5 度）
2. 用現有的 `tools/topojson.php`（已經會在交界點把界線切成「弧」、共用的弧只存一次）切出所有弧
3. **每條弧只簡化一次**，兩端的交界點固定不動（Douglas-Peucker 或 Visvalingam，容許值沿用現在各層的值，可再調）
4. 用簡化後的弧重組每個單位的形狀，照現在的格式輸出 `map_*.json`（SVG 路徑）→ **前端完全不用改**
5. 相鄰的單位共用同一條簡化後的弧，所以不會有縫，相鄰關係也跟原圖一樣；局部形狀失真可以接受

需要注意：

- 很短的弧（兩個交界點靠很近）簡化後只剩兩端，形狀可能變成細長三角形 → 設「每個環至少保留 4 個點」
- 小島：改用「面積門檻＋每個縣市至少保留最大的幾塊」，或離島範圍另外用較小容許值
- 驗證：匯出時比對「原圖相鄰的鄉鎮配對」與「簡化後共用弧的配對」是否完全一致，並列出面積差最大的幾個單位；結果寫進匯出訊息

### 其他選項（不建議優先）

- PostGIS 的 `ST_CoverageSimplify`：一次簡化整片相鄰區域、不留縫，但要 PostGIS 3.6／GEOS 3.12 以上。本機是這幾個月才裝的，可能夠新，但 pgAdmin 畫面看不出版本；開新對話時先在 pgAdmin 連 **photo_monitor**（不是 access_db）執行唯讀查詢 `SELECT postgis_full_version();` 確認；版本夠的話這是最省事的做法
- mapshaper（Node.js 工具）：效果好，但要多裝一套工具，和現在 PHP＋PostGIS 的匯出流程不一致

### 待決定

- 先做哪一層：建議鄉鎮（主畫面）→ 縣市 → 村里
- 檔案大小上限：簡化變少時檔案會變大或變小，要定一個可接受的大小

## 二、制霸戳章與彩蛋

### 戳章（概念）

- 樣子：半透明的紅色圓形印章，中間是毛筆風格的「制霸」兩字，蓋在卡片右上角、稍微旋轉
- 字體版權：**不用任何字型檔**，由我們自己用 SVG 路徑畫出筆畫（粗細不均的筆刷線條），加上 SVG 濾鏡做出印泥不均的質感；這樣沒有字型授權問題
  - 備案：開源授權（SIL OFL）的毛筆字型可以轉成路徑使用，但要附授權聲明，而且要確認字型有「霸」這個字
- 同一組路徑要能同時用在網頁（SVG）和分享成就圖片（canvas 用 Path2D 畫），兩邊長得一樣

### 彩蛋（概念）

- 特定成就**這次新解鎖**時，跳出一個小彈窗，附歌曲連結（例如〈島嶼天光〉、〈海島冒險王〉）
- 不嵌入 YouTube 播放器：嵌入會在使用者沒點之前就連到 YouTube、帶入追蹤 cookie，違反「不加追蹤」的原則 → 只放按鈕，點了才另開分頁；說明頁的對外連線表要補上
- 連結要用官方頻道的影片網址，由維護者提供（不自己找，避免連到非官方上傳）
- 「新解鎖」怎麼判斷：把已達成的成就清單存在這台瀏覽器，每次算完比對，多出來的才算新解鎖
  - 第一次匯入會一次解鎖很多 → 只跳一個（優先度最高的），或改成一個「這次解鎖了 N 項」的總結彈窗
- 要有開關可以關掉彩蛋；手機上彈窗不能擋住操作

### 維護者已決定（2026-11-21）

- 戳章蓋在三個地方，都在**右上角**：
  1. 成就徽章卡片：該成就達成 100% 時
  2. 縣市制霸集點卡的格子：取代現在的橘色打勾
  3. 鐵道（臺鐵等）與捷運：某條線全部到站時，蓋在那條線的卡片上
- 彩蛋是「獎勵」：只放按鈕、點了另開分頁，以不違反「不加追蹤」為優先
- 只有真正困難的成就才有彩蛋：
  - 鄉鎮全部制霸 → 〈島嶼天光〉（維護者說明：現在網路上普遍拿這首歌玩梗，不擔心政治解讀）
  - 本島四極制霸 → 〈海島冒險王〉
  - 其他之後再補
- 第一次匯入時，達成的彩蛋全部都跳（本來就很難有人做到）
