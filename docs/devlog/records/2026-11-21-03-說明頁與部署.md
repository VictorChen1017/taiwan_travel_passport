## 做了什麼

- 查證圖磚供應商現況（2026-11）：OSM 政策、CARTO（現在需要 API key）、OpenFreeMap（不用 key，需 MapLibre）、國土測繪中心（授權原文未查到），結果寫在 SPEC §16
- `js/tiles.js`（新）：OSM 改用不帶子網域的 `tile.openstreetmap.org`、標示連到版權頁、`referrerPolicy: strict-origin-when-cross-origin`
- `help.html`、`css/help.css`（新）：使用步驟、各平台時間軸匯出方式、計算規則、手動紀錄、報表、備份、隱私與對外連線表、授權、已知限制、常見問題
- 入口：頂列「❓ 說明」、首頁介紹、本機運算說明、頁尾；≤ 1000 px 說明與報表按鈕只留圖示，≤ 640 px 移到目錄抽屜
- 推上 GitHub 前檢查追蹤的檔案：沒有帳密（`tools/lib.php` 只讀 `.env`）、`test/` 已忽略
- `git remote add origin` → `git push -u origin master`
