## 目標

把成就頁的結果做成一張可以分享的 PNG 圖片，只含地名與日期，不含座標與照片。

## 決定

| 問題 | 決定 | 決定者・理由 |
|---|---|---|
| 圖片尺寸 | 寬 1080 px 長圖，高度依內容 | 維護者：手機、社群都好看，一張搞定 |
| 標題列 | 「🛂 台灣旅遊護照」＋選填暱稱＋紀錄期間與製作日期 | 維護者 |
| 迷霧地圖層級 | 預設鄉鎮，可切換縣市／村里（每年新解鎖跟著切換） | 維護者 |
| 預設組合 | 足跡總覽、制霸卡、登山、鐵道、旅人、完整（內容見 SPEC §15.4） | 維護者（Claude 提案） |
| 繪製方式 | 直接用 Canvas 2D，不用 html2canvas、不用 SVG foreignObject | Claude：各瀏覽器結果一致、不會有畫布被汙染無法輸出的問題、不多載入套件 |

## 做了什麼

- `js/report.js`（新）：報表彈窗（左選項、右預覽）與繪製；先「量」高度再依總高度建立畫布真正畫（`Painter.dry`）
- `js/shared.js`（新）：從 `explore.js` 抽出資料色、徽章圖示與外框；外框全部改寫成 path，SVG 與 Canvas `Path2D` 共用，報表與成就頁畫出來一樣
- `css/report.css`（新）：彈窗樣式，只用 `--c-*`
- `js/app.js`、`index.html`：頂列與目錄的「🖼 成就報表」入口、紀錄期間與手動紀錄筆數

## 驗證

- 六種組合都產生成功；「完整」1080 × 12,288 px、PNG 約 2 MB、繪製 30～90 毫秒
- 淺色、深色、隱藏日期、暱稱、村里地圖、手機寬度（375 px）截圖確認；console 無錯誤
- 成就頁徽章改用共用 path 後外觀不變

## 遇到的問題

- 捷運黃線、淺綠線格子上的白字看不清楚 → 依路線色亮度改用深色字
- 臺鐵格子顏色沒有說明 → 補站級圖例
- 里程碑依縣市／鄉鎮／村里分三列很空 → 里程碑不分小標題；第一次修改時把篩選條件寫錯（分區鍵和篩選不一致會讓里程碑全部消失），當場發現改正
- 手機寬度下彈窗底部按鈕被擠成直排 → 窄畫面讓尺寸文字獨占一行、按鈕不換行

## 留下的事

- 只測了「產生 PNG」，沒有打開下載後的檔案檢查；手機的系統分享選單沒有實機測試
- 超過 8,000 px 的長圖在部分手機 App 可能無法完整顯示（介面已提示）
