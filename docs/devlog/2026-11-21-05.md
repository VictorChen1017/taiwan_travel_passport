# 開發日誌 2026-11-21 第 5 份

期間：第 4 份之後 ～ 2026-11-21 晚｜commit：本份日誌與功能同一個 commit

## 完成的功能

- 使用說明改為另開分頁：成就頁不換頁、不重算，側邊欄不消失
- 「?」說明鈕：點一下顯示說明泡泡（手機可用），用在「包含移動路徑」（原「包含移動途中」）、「隱藏日期」、行政區尺度的「村里」
- 手動加入車站／山：在集點卡點某個未到的站，或在明細地圖點灰點，按鈕直接帶入那一站，只要選日期
- 分享成就
  - 未達成預設顯示；勾選的區塊下方展開進階選項：隱藏未達成、選子項目
  - 子項目：鐵路（高鐵、臺鐵北／中／南／東／支線、林鐵）、捷運與輕軌各系統、登山、景點（北中南東）、國家公園與保護區（4 類）
  - 每年新解鎖加累積曲線（預設開）；村里探索進度可選一個縣市改列各鄉鎮（選單依六都、其他縣市、離島排序）
  - 縣市制霸卡註明格子是鄉鎮進度；「臺鐵・高鐵」改名「鐵路」、「旅行」改名「旅行成就」
  - 暱稱沒填時預覽顯示淡色「小明的足跡」，下載時不印；手機按鈕改「分享／儲存」
  - 拿掉「迷霧地圖最細到鄉鎮」，改成「行政區尺度」三選一按鈕（縣市｜鄉鎮｜村里 ?）
- 自動檢查新增 3 項（鐵路子項目、景點與保護區子類別、累積曲線與縣市選單），共 17 項全過

## 克服的難題

- 原生下拉選單的選項放不了可點的「?」→ 行政區尺度改成三個並排的選項按鈕
- 選項欄出現橫向捲軸 → 選單寬度被最長的選項撐開，改成固定滿版寬度
- 累積折線壓到長條上的數字 → 先畫長條、再畫折線、最後畫墊底色的數字

## 對話檢討

- 做得好的：每輪回饋都用 selftest＋少量畫面確認；拿不準的地方（縣市選單放哪）先問再做

- 下次的做法：介面配置不確定時先用一句話描述擺法給維護者確認；需求數量和資料對不上時先問
