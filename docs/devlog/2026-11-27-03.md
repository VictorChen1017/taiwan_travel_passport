# 開發日誌 2026-11-27 第 3 份

期間：第 2026-11-27-02 份之後 ～ 2026-11-27｜commit：本份日誌與功能一起 commit、push

## 完成的功能

- 匯出影片改成一格一格交給編碼器（WebCodecs）：每一格標上它在影片裡的時間，手機卡頓不會錄進影片，也不用等實際時間
  - MP4 封裝自己寫（和 GIF 一樣不用外部套件）；H.264、固定 30fps、每 2 秒一個關鍵格
  - 按鈕改成「產生影片」、進度顯示「產生中」；不支援的瀏覽器才顯示「開始錄製」並提醒不要切換 App
- 不支援 WebCodecs 的瀏覽器退回原本的即時錄製，換格時間改成對準整條時間軸，影片不會越錄越長

## 克服的難題

- 維護者實測「村里＋全島＋3×」開頭結尾會卡 → 即時錄製本身的限制，改成編碼器逐格標時間
- 檢查成品：測試瀏覽器擋影片播放 → 用開發伺服器存檔，再用本機 ffprobe／ffmpeg 確認（H.264 High、1080×1920、30fps、26.8 秒、整段解碼無錯誤，抽三張畫面確認內容）
- 分頁在背景時計時器被放慢到每秒一次 → 讓出執行緒改用 MessageChannel、等編碼器改用 dequeue 事件

## 對話檢討

- 做得好的：用 ffprobe 實際檢查檔案，不只看「有產生檔案」
- 要改進的：測試時又忘了開發用測試資料不會保存，重新整理後白跑幾輪；電腦記憶體吃緊時壓力測試應先問過
- 下次的做法：重新整理後先重新載入測試資料；大檔、長時間的測試先跟維護者確認
